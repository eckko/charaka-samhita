# Glossary: fixed renderings for all chunks (extended by reviewers)
Draft status: AI drafts, not read by a person.
- āyurveda = Āyurveda (the science of life); ṛṣi = sage; bhiṣak/vaidya = physician; bhagavān ātreyaḥ = the venerable Ātreya
- vāta, pitta, kapha = Vāta, Pitta, Kapha (Hindi वात, पित्त, कफ); doṣa = doṣa (दोष); dhātu = dhātu (धातु); mala = waste (मल)
- rasa = taste (of the six tastes) or rasa; vipāka, vīrya, prabhāva: keep the Sanskrit with a gloss
- sthāna = section; adhyāya = chapter; agniveśa = Agniveśa; proper names plain IAST in English
- Plant identifications: tag standard/probable/disputed in notes only.
- kṣīra/payas = milk, or latex when from a plant (Hindi दूध); phalinī/mūlinī = fruit-yielding / root-yielding plants
- yoga (of drugs) = application (yoga); yukti = rational planning (yukti)
- vamana = emesis; virecana = purgation; āsthāpana = decoction enema; snehana = oleation; nasya = nasal therapy
- śamana = pacifying; śodhana = purifying; sneha = unctuous substance; bheṣaja/auṣadha = medicine; siddhi = success
- Vāsava = Vāsava (Indra), epithet first
- Chapter colophons stay verbless: no "thus ends" in English, no "समाप्त" in Hindi
- śakra = Śakra (Hindi शक्र, not इन्द्र); Indra's epithets (Śatakratu, Sahasrākṣa, Śacīpati, Balahantṛ, Amaraprabhu) and pitāmaha = the Grandsire (पितामह) stay epithets, name only in notes
- maharṣi = great sage (महर्षि); devarṣi = divine sage (देवर्षि); tantra = treatise (तन्त्र)
- sāmānya = sameness (sāmānya); viśeṣa = difference (viśeṣa); dravya = substance; guṇa = quality; samavāya = inherence; sattva (mind) = mind (sattva); ātman = self
- vāyu/māruta = Vāta (Sanskrit word in brackets); śleṣman = Kapha (śleṣman)
- loha = metal (लोह), not धातु; mala of metals = dross (mala = waste only for the body)
- mūlinī = root-drug (मूलिनी); phalinī = fruit-drug (फलिनी); sneha = fat/unctuous (स्नेह); kuṣṭha, udara, gulma kept as Sanskrit; śvāsa = dyspnoea; kāsa = cough; anuvāsana = unctuous enema; nirūha = decoction enema; śirovirecana = head-evacuation
- Hindi keeps the Sanskrit term (e.g. क्षीर) instead of an explanation "अर्थात् …"; plant identifications in notes only, not in gloss/translation
- samīraṇa = Vāta (samīraṇa); kopayati (causative of kup) = aggravate (कुपित करना)
- vega = urge (वेग); nigraha/dhāraṇa/vidhāraṇa = suppression (रोकना); sveda = sweating (स्वेद); abhyaṅga = oil massage (अभ्यङ्ग); avagāhana = immersion bath; varti = suppository (वर्ति); dhūma = medicated smoking (धूम); nāvana = nasal therapy; laṅghana = lightening; saṃvāhana = massage
- śūla = pain (शूल); aṅgamarda = body-ache (अङ्गमर्द); aruci = loss of taste (अरुचि); bhrama = giddiness (भ्रम); śrama = fatigue (श्रम); klama = exhaustion (क्लम); chardi = vomiting (छर्दि); hṛdroga = heart disease (हृद्रोग)
- vātaghna = Vāta-destroying; vātānulomana = moving Vāta downward; agni = digestive fire (agni, अग्नि); vyāyāma = exercise (व्यायाम); grāmyadharma = sexual intercourse (grāmyadharma)
- disease names stay Sanskrit: pāṇḍu, ardita, ardhāvabhedaka, raktapitta, pratāmaka, vīsarpa, mūtrakṛcchra, kuṣṭha, gulma
- sauhitya = satiety (सौहित्य); ūrdhvajatru = above the collar-bones (ऊर्ध्वजत्रु); dhūmanetra = smoking-pipe; abhyaṅga=massage; gaṇḍūṣa = held in mouth, kavala = moved in mouth; alakṣmī = misfortune
- hṛṣyante/dantaharṣa = teeth set on edge, Hindi सिहरन (never हर्षित); vṛṣya = aphrodisiac; āyuṣya = promoting life; ojas = ojas (vital essence), glossed at first use
- nagarin = city-lord (नगर का स्वामी, not नगरी); rathin = chariot-owner (रथी); gṛdhrasī = gṛdhrasī (identifications in notes only); niṣevaṇa = use; pādatra = footwear; dantapavana = tooth-stick
- bhavati cātra = "And here there is:"; tatra ślokāḥ = "Here, the verses:"; vāyu/māruta in Hindi = वायु/मारुत
- yavāgū = gruel (यवागू); peyā = thin gruel (पेया); takra = buttermilk (तक्र); niryūha = soup/decoction; māṃsarasa = meat-juice; pañcakarma = the five procedures (पञ्चकर्म); atisāra = diarrhoea; viṣamajvara = irregular fever; āmāśaya, pakvāśaya kept as Sanskrit
- dīpana = stimulating digestion; pācana = digesting; grāhin/sāṃgrāhika = binding; bṛṃhaṇa = nourishing; karśana = reducing; virūkṣaṇa = drying; bhedin = breaking (purgative); vyāpad = ill effect
- nāgara/viśva (n.) = dry ginger (Sanskrit name kept); Ślokasthāna = Śloka section (Ślokasthāna); śleṣman in Hindi = श्लेष्मा
- vāyu as an element (with agni, pṛthvī, soma) = air (वायु), not Vāta; soma with pṛthvī = soma (सोम)
- āntarīkṣa payas = rain-water (आन्तरिक्ष जल) — exception to payas = milk
- añjana = collyrium (अञ्जन); sauvīrāñjana, rasāñjana kept; āścyotana = eye-drops (आश्च्योतन); varti = wick (वर्ति); dhūmapāna = smoking (धूमपान)
- smoking kinds: prāyogikī = regular, snaihikī = unctuous, mūrdhavirecana = head-evacuating (prāyogikī/snaihikī agree with varti, feminine)
- mātrā = measure (मात्रा); guru/laghu = heavy/light (गुरु/लघु); svasthavṛtta = regimen of the healthy (स्वस्थवृत्त); nāvana = nasal therapy (नावन)
- tvak/tvac (plant bark) = bark (छाल), not त्वचा; payas/kṣīra in Hindi = दूध, never पय (chagalīpayas = बकरी का दूध)
- pradeha = plaster (प्रदेह); lepa = paste (लेप); ālepana = ointment (आलेपन); udvartana = rubbing (उद्वर्तन); avacūrṇana = dusting (अवचूर्णन); pragharṣa = rubbing; nirvāpaṇa = cooling (निर्वापण)
- sitopalā = sugar candy (सितोपला); śirorujā = headache (शिरोरुजा); karṣa, āḍhaka kept as measures (values in notes only)
- dhūma kinds: prāyogika/snaihika/vairecanika = regular/unctuous/evacuative smoking (प्रायोगिक/स्नैहिक/वैरेचनिक); dhūmanetra = smoking pipe; bastinetra = enema nozzle; aṇutaila = Aṇu oil (अणुतैल)
- nāvana = nasal therapy in English too, never "nasal medication"; supīta/apīta/atipīta (dhūma) = well drunk/not drunk/drunk in excess; picu = swab; uttamāṅga = head; jantu = person (जन्तु/प्राणी)
- dantaviśodhana = tooth-cleanser; jihvānirlekhana = tongue-scraper; tarpaṇa kept Sanskrit; disease names kept Sanskrit: śaṅkhaka, rohiṇī, meha, madātyaya, timira, pīnasa, manyāstambha, hanusaṃgraha
- gram: gerundives labelled "gerundive (kṛtya)", never "ger."; eva = emphatic particle ("just, indeed"), not "or else"
- kāyāgni = digestive fire of the body; paktā = the digester (पचाने वाला); kavalagraha = holding a mouthful, moved in the mouth; utsādana = rubbing with unguents; ādāna = ādāna (taking up); visarga = visarga (release); ṛtusātmya/okaḥsātmya/sātmya = suitability (seasonal/habitual/general)
- Season names stay Sanskrit in English (Śiśira, Vasanta, Grīṣma, Varṣā, Śarad, Hemanta), equivalents in notes only; kept Sanskrit: mantha, udamantha, madirā, śīdhu, mādhvīka, ariṣṭa, yūṣa, haṃsodaka, māhendra water
- jāṅgala = dry-land; audaka = aquatic; ānūpa = marsh; bileśaya = burrow-dwellers; vasā = muscle-fat; kṣāra = alkali; kṣaudra = honey; physical wind (vāyu/māruta/anila) = wind
